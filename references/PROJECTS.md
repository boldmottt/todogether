# 레퍼런스 프로젝트 목록

## 1. Donetick
- **링크**: https://github.com/donetick/donetick
- **라이선스**: AGPL-3.0 ⚠️
- **가져올 점**: 공유방(Circle) 개념, 역할별 권한(owner/member), 반복 규칙 UI
- **주의**: 코드 직접 복사 금지

## 2. Vikunja
- **링크**: https://github.com/go-vikunja/vikunja
- **라이선스**: AGPL-3.0 ⚠️
- **가져올 점**: 프로젝트/리스트/태스크 계층, 담당자 지정, 반복 설정 모델
- **주의**: 코드 직접 복사 금지
